# OmniCalc — Precision Online Calculator Portal

A lightning-fast, privacy-first, and responsive multi-calculator web suite for financial, health, mathematical, and everyday utility calculations.

## ✨ Features

- **Finance Utilities:**
  - **Loan & Mortgage EMI Calculator:** Monthly payment, total interest, principal breakdown, and interactive amortization schedule.
  - **Compound Interest Calculator:** Long-term growth projection with monthly deposits and annual compounding.
- **Health & Fitness:**
  - **BMI Calculator:** Metric and Imperial BMI calculation with interactive health range indicator.
  - **TDEE & Calorie Deficit Calculator:** Total Daily Energy Expenditure calculation based on Mifflin-St Jeor formula.
- **Everyday Math & Text:**
  - **Percentage Calculator:** Three calculation modes with percentage increase and decrease.
  - **Discount & Sales Tax Calculator:** Multi-tier discounts with tax breakdown.
  - **Age & Date Difference:** Exact year, month, and day calculations.
  - **Word Counter:** Character, word, reading, and speaking time estimates.

## 🚀 Tech Stack

- **Framework:** React 19 + TypeScript + Vite
- **Styling:** Tailwind CSS
- **Icons:** Lucide React
- **Privacy:** 100% Client-Side calculation (zero user data leaves the device)

## 🛠️ Local Development

```bash
# 1. Install dependencies
npm install

# 2. Start local development server
npm run dev

# 3. Build for production (includes dynamic sitemap generation)
npm run build
```
